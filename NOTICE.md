# Attribution and inherited metadata

Upstream: https://github.com/hku-mars/FAST-LIVO2

Original LICENSE and source copyright headers are preserved. UPSTREAM_README.md is a copy of the original working-tree README. Original package.xml is preserved, including upstream maintainer details; these are not the identity of this research fork's maintainer.

The original README identifies GPLv2 and the LICENSE contains the GNU GPL text, while inherited ROS package metadata says BSD. This export records the discrepancy and does not invent a new license grant. Review that metadata before a formal release; do not relabel the code MIT/BSD based solely on package.xml.

Research additions and uncommitted working-tree source are included where required by the selected build targets. SOURCE_MANIFEST.json records their exact file hashes. Third-party datasets, model weights, papers and large generated artifacts are not redistributed.
