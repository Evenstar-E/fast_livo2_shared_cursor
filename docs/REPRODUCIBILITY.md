# 复现与数据边界

这是一份精简源代码发布，不是完整实验存档。普通 mapper 源码、核心测试和学习模块可阅读；已发表式结果复现尚不具备全部输入。

## 外部输入

- bag、标定和真值须从各数据集官方渠道获取并遵守其条款，本包不再分发。
- exp04/07/16 都已经参与开发，不能称为未见测试集。
- exp16 没有 Leica 真值；clean LIO 地图不是外部地图真值。
- 共同端点位置差、邻位移差、六弦长均不能改称正式 ATE/RPE；禁止跨真值空窗插值。
- 模型权重、归一化统计、分区与训练输入没有随包发布。不能从模型结构文件单独重现冻结模型的结果。

## 复现近期隔离实验仍需

对应生成构建源码（含冻结的 voxel_map 版本）、原始输入签名账本、模型及融合参数、全部运行参数和评测来源。原开发目录保存这些内容，精简包没有伪造下载地址或成功复现声明。

## 验证层级

导出 SHA 和依赖检查只证明文件选择完整；单元回归不证明恢复有效；普通 mapper 编译不证明 dated 私有原型等价。完整联合实验、新 clean、独立健康、公开切换及 1× 仍须分别验收。
