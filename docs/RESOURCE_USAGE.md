## 运行内存

最近失败的exp16交接运行峰PSS+swap约12.85GiB。监督器发现WSL剩余RAM+swap不足1GiB后停止，未达到20GiB进程预算；不是已证实的kernel OOM。该运行只有1191事件完整前缀，最终地图指标UNKNOWN。

已确认的内存机制：工作地图与候选地图、checkpoint地图副本、历史点云/IMU和修改日志、匹配临时数组，以及加载模型的进程。每个点/体素还包含索引、法向、协方差和管理结构；PCD磁盘大小不能直接等同运行内存。
